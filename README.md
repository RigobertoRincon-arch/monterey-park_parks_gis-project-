# monterey-park_parks_gis-project
Park Accessibility Analysis – Monterey Park, CA

Overview:

This project analyzes park accessibility and amenities in Monterey Park using GIS web mapping tools. An interactive StoryMap and web application were developed to visualize spatial differences in park facilities.

Tools Used:

ArcGIS Online

ArcGIS Experience Builder

ArcGIS StoryMaps

Arcade expressions for custom pop-ups

Key Features:

Interactive map of parks in Monterey Park

Custom pop-ups displaying park amenities

Web-based StoryMap summarizing findings

Spatial analysis of park accessibility

Key Findings:

Park amenities are unevenly distributed across the city

Some parks provide full recreational facilities, while others are limited

Spatial differences may impact accessibility for residents
